# How I Think About Debloating Windows Conservatively

I prefer conservative debloating: remove clearly unnecessary apps, create restore points, understand dependencies, avoid random scripts from unknown sources, verify before deleting services.
Breaking Windows for marginal disk savings creates support debt.
