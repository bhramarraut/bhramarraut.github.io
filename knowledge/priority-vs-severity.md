# Priority vs Severity: Related but Not the Same

**Severity** describes how bad the issue is technically or for the user experience. **Priority** describes how soon it should be addressed given business context.
A low-severity cosmetic issue on a CEO demo screen may have high priority. A severe data corruption bug affecting one internal test account may have low priority.
