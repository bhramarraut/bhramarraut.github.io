# What OWASP ZAP Is — and What It Is Not

OWASP ZAP is a free security testing tool for finding vulnerabilities in web applications during authorized testing.
It is not a replacement for professional penetration testing or a tool for unauthorized scanning.
**Source:** [OWASP ZAP](https://www.zaproxy.org/)
