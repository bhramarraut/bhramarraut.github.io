# Essential Windows Commands in My Toolkit

`ipconfig` — View network adapter configuration. Useful for IP, gateway and DNS checks. Low risk.
`ping` — Test reachability to host. Useful for basic connectivity.
`tracert` — Trace route to host. Useful for network path issues.
`nslookup` — DNS resolution queries.
`netstat` — Active connections and listening ports.
`tasklist` / `taskkill` — Process inspection; kill only when identified safely.
`sfc /scannow` — System file check. Requires admin. Can take time.
`DISM` — Image repair. Admin required. Use official Microsoft guidance.
`chkdsk` — Disk check. Can be disruptive; schedule appropriately.
**Source:** [Microsoft Windows Commands](https://learn.microsoft.com/en-us/windows-server/administration/windows-commands/windows-commands)
