# How I Use AI Agents Without Pretending AI Output Is My Manual Coding

My workflow with Cursor, Codex, Antigravity and Ollama:
- **Define requirement** → what should the system do?
- **Constrain context** — scope, constraints, acceptance criteria
- **Generate** — AI produces implementation
- **Inspect** — read output, don't blindly accept
- **Test** — run workflows manually
- **Identify failures** — expected vs actual
- **Iterate** — refine prompts and corrections
- **Validate** — confirm fix meets original expectation
- **Document** — record behavior and decisions
**Human accountability:** Requirements, judgment, testing and correctness remain human responsibilities.
