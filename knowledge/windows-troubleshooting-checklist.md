# My Windows Troubleshooting Checklist

Before assuming hardware failure:
- Recent software or update changes?
- Reproducible after restart?
- Event Viewer errors around failure time
- Disk space and memory pressure
- Network connectivity (if cloud-dependent)
- User profile vs system-wide issue
- Safe Mode behavior
- Driver or peripheral changes
