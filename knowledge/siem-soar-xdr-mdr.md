# SIEM vs SOAR vs XDR vs MDR: My Mental Model

**SIEM:** Aggregates and correlates security logs for detection.
**SOAR:** Orchestrates and automates security response workflows.
**XDR:** Extended detection across endpoints, network, cloud.
**MDR:** Managed service provider operates detection and response.
I am not a cybersecurity professional — this is awareness-level understanding.
