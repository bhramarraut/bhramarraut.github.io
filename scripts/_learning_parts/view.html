06 / Method

Learning → evidence

Learning is only useful when it becomes proof — notes, labs, projects or credentials.

  1. Learn
  2. Practice
  3. Build
  4. Document
  5. Explain
  6. Apply

Example: learn SQL joins → practice queries → build a small support-data check → document in Obsidian → publish a Knowledge note → apply in a troubleshooting scenario.
